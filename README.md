# Reproducibility Materials

This repository contains R code for the manuscript **“Minimaxity and Admissibility of Bayesian Neural Networks.”**

## Contents

- **Section 5.1 simulations:** Risk comparisons between the maximum likelihood estimator, fixed-scale Bayesian neural networks, Bayesian neural networks with dropout, and the proposed Beta-prime hyperprior.
- **Section 5.2 simulations:** Risk comparisons between the proposed minimax Bayesian neural network estimator and the horseshoe estimator under different sparsity levels.

## How to run

Open the relevant R scripts and run them in R or RStudio.
